# Lumi

Lumi is a personal knowledge management system for collecting, converting, storing, and reading web content.

## Workspace

- `apps/web`: Vue 3 web client
- `apps/server`: NestJS API server
- `apps/extension`: WXT browser extension
- `apps/cli`: reserved CLI package
- `packages/shared`: shared types and constants
- `packages/api-client`: API client SDK
- `packages/parser`: content parsing utilities
- `packages/ai`: AI provider abstractions
- `packages/storage`: object storage abstractions

## Scripts

```bash
pnpm dev:web
pnpm dev:server
pnpm dev:extension
```
