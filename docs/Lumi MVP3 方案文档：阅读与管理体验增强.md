# Lumi MVP3 方案文档：阅读与管理体验增强

## 1. 背景

MVP0 已完成 Lumi 的 Monorepo 项目结构搭建；MVP1 已打通 Web 端 URL 导入、解析、入库与阅读详情闭环；MVP2 已补全浏览器插件的 URL/HTML 导入闭环。

MVP3 的目标不再是继续扩展导入入口，而是让已导入内容变得更容易浏览、筛选、整理和阅读。也就是说，Lumi 需要从“能保存文章”推进到“愿意长期打开使用的个人知识库工作台”。

## 2. MVP3 目标

MVP3 聚焦 Web 端阅读与管理体验增强：

- 优化文章列表页布局，采用左侧筛选栏 + 右侧信息卡片列表。
- 支持标题、摘要、正文文本关键词搜索。
- 支持按状态、类型、标签、来源域名筛选。
- 支持按创建时间、更新时间排序。
- 支持手动纯文本标签，详情页添加和删除标签。
- 支持归档、取消归档、删除到回收站、恢复、永久删除。
- 优化详情页阅读排版和管理操作。
- 整体 UI 风格以安静高效的知识库界面为主，兼具现代产品完成度。

## 3. 非目标

MVP3 暂不包含以下能力：

- AI 自动摘要、自动标签、内容问答。
- 批量归档、批量删除、批量加标签。
- 标签颜色、标签层级、标签合并。
- PostgreSQL 全文搜索索引。
- 三栏预览式工作台。
- 移动端复杂管理操作优化。

## 4. 产品范围

### 4.1 文章列表页

列表页采用两栏工作台布局：

- 左侧筛选栏：
  - 搜索框。
  - 状态筛选：全部、已归档、回收站。
  - 类型筛选：全部、文章、视频、音频、PDF、片段。
  - 标签筛选：展示所有标签和关联文章数量。
  - 来源筛选：展示所有来源域名和关联文章数量。
- 右侧内容区：
  - 顶部展示当前结果数量、排序控件、导入入口、退出登录入口。
  - 文章以横向信息卡片展示。
  - 卡片展示标题、摘要、来源、类型、字数、时间、标签。
  - 卡片提供打开详情、归档/取消归档、删除/恢复/永久删除等轻量操作。

默认列表规则：

- 默认状态为“全部”，只展示未归档且未删除的文章。
- “已归档”视图展示 `archivedAt` 不为空且 `deletedAt` 为空的文章。
- “回收站”视图展示 `deletedAt` 不为空的文章。
- 回收站文章仍可打开详情阅读。

### 4.2 搜索

搜索范围：

- 标题 `title`
- 摘要 `excerpt`
- 正文纯文本 `contentText`

MVP3 使用 Prisma `contains` + `insensitive` 实现轻量搜索，不引入全文索引。

### 4.3 排序

支持四种排序：

- 最新创建：`createdAt desc`
- 最早创建：`createdAt asc`
- 最近更新：`updatedAt desc`
- 最早更新：`updatedAt asc`

默认排序为最新创建。

### 4.4 标签

标签系统为手动纯文本标签：

- 标签只有名称，不包含颜色、层级和描述。
- 标签名保存前 trim。
- 空标签不可添加。
- 同一用户下标签名称唯一。
- 同一文章不可重复添加同一标签。
- 列表页只展示和筛选标签。
- 详情页支持添加和删除标签。

### 4.5 归档与回收站

归档：

- 未删除文章可以归档。
- 已归档文章从默认列表隐藏。
- 已归档视图可取消归档。
- 归档和取消归档不需要二次确认。

删除：

- 删除到回收站时需要确认。
- 回收站文章可恢复。
- 回收站文章可永久删除。
- 永久删除需要确认。
- 恢复不需要确认。

详情页规则：

- 普通文章支持归档、删除到回收站、标签编辑。
- 已归档文章支持取消归档、删除到回收站、标签编辑。
- 回收站文章支持恢复、永久删除。
- 回收站文章不提供归档操作。

## 5. 数据设计

### 5.1 Document

新增字段：

- `archivedAt DateTime?`

已有字段继续使用：

- `deletedAt DateTime?`

含义：

- `archivedAt = null && deletedAt = null`：默认活跃文章。
- `archivedAt != null && deletedAt = null`：已归档文章。
- `deletedAt != null`：回收站文章。

### 5.2 Tag

新增模型：

- `id`
- `name`
- `createdAt`
- `updatedAt`
- `userId`

约束：

- 同一用户下 `name` 唯一。

### 5.3 DocumentTag

新增文章与标签关联模型：

- `documentId`
- `tagId`
- `createdAt`

约束：

- `documentId + tagId` 唯一。
- 删除文章或删除标签时级联删除关联关系。

## 6. API 设计

### 6.1 查询文章列表

`GET /api/documents`

查询参数：

- `keyword`
- `page`
- `pageSize`
- `status`: `active | archived | trash`
- `type`
- `tag`
- `source`
- `sort`: `created_desc | created_asc | updated_desc | updated_asc`

返回：

- 分页文章列表。
- 每篇文章包含标签、归档状态、删除状态。

### 6.2 查询筛选元数据

`GET /api/documents/facets`

返回：

- 标签列表及数量。
- 来源域名列表及数量。

### 6.3 查询文章详情

`GET /api/documents/:id`

规则：

- 可以查询活跃、归档、回收站文章。
- 回收站文章由响应字段标识状态。

### 6.4 状态操作

- `PATCH /api/documents/:id/archive`
- `PATCH /api/documents/:id/unarchive`
- `PATCH /api/documents/:id/restore`
- `DELETE /api/documents/:id`
- `DELETE /api/documents/:id/permanent`

### 6.5 标签操作

- `POST /api/documents/:id/tags`
  - body: `{ "name": "前端" }`
- `DELETE /api/documents/:id/tags/:tagId`

## 7. Web 端设计

### 7.1 列表页

布局：

- 页面使用工作台式布局，不做营销页。
- 左侧筛选栏固定承载筛选入口。
- 右侧信息卡片列表强调快速扫描和整理。

卡片操作：

- 打开详情。
- 活跃文章：归档、删除。
- 归档文章：取消归档、删除。
- 回收站文章：恢复、永久删除。

### 7.2 详情页

阅读排版：

- 控制正文宽度。
- 优化标题、元信息、正文 markdown 间距。
- 展示来源、作者、字数、发布时间、创建时间。
- 原文链接使用新窗口打开。

管理操作：

- 返回列表。
- 打开原文。
- 标签添加和删除。
- 归档/取消归档。
- 删除到回收站。
- 恢复。
- 永久删除。

## 8. 验收标准

- 用户可以在默认列表查看未归档、未删除文章。
- 用户可以按关键词搜索标题、摘要和正文。
- 用户可以按类型、标签、来源筛选文章。
- 用户可以按创建时间和更新时间排序。
- 用户可以在详情页添加和删除标签。
- 用户可以在列表页通过标签筛选文章。
- 用户可以归档文章，并在归档视图取消归档。
- 用户可以删除文章到回收站，并从回收站恢复。
- 用户可以永久删除回收站文章。
- 回收站文章可以打开详情阅读。
- Web UI 比 MVP1/MVP2 更适合长期阅读和管理。
- `pnpm build:server`、`pnpm build:web` 通过。

## 9. 后续扩展

MVP3 完成后，后续版本可以继续扩展：

- AI 自动摘要和自动标签。
- PostgreSQL 全文搜索。
- 批量管理。
- 标签颜色、标签合并、标签别名。
- 阅读进度和收藏夹。
- 文章内容问答。
