# 5. apps 和 packages 的区别

## apps

`apps` 下面一般放最终产品。

例如：

```txt

apps/web          Web 前端

apps/server       后端服务

apps/extension    浏览器插件

apps/cli          命令行工具

```


它们可以独立启动、构建、部署。
例如：
```bash

pnpm --filter web dev

pnpm --filter server start:dev

pnpm --filter extension dev

pnpm --filter cli build

```

## packages

`packages` 下面放公共能力。

例如：

```txt

packages/shared       公共类型

packages/parser       网页解析逻辑

packages/markdown     Markdown 工具

packages/api-client   API 请求 SDK

packages/config       统一配置

```
这些通常不会直接运行，而是被 `apps` 使用。
